# Data Collection Plan

| Item | Decision |
|---|---|
| **Data type** | Primary data (new survey) |
| **Why not secondary?** | Existing datasets rarely measure bedtime screen time specifically |
| **Population** | College students aged 18+ |
| **Sampling technique** | Convenience sampling via class groups and social media (simple, but not random) |
| **Target sample size** | 60+ responses (practice); 100+ for real research |
| **Tool** | Google Forms |

## Survey Questions
1. Age (number)
2. Gender (optional)
3. On average, how many **hours** do you use a screen in the hour(s) before bed? (0–4+)
4. Rate your overall sleep quality last week (1 = very poor, 10 = excellent)
5. How many hours did you sleep on average? (optional control variable)

## Ethical Considerations
- Voluntary participation with an informed-consent statement at the top
- Anonymous: no names, emails, or IDs collected
- Participants can skip questions or quit anytime
- Data stored securely and used only for this study
